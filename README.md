    g++ -std=c++17 ServiceCenter.cpp -o service_center
Запуск:
    ./service_center
    
InventoryItem - базовый класс. От него наследуются EnergyConsumer, чтобы учитывать потребление энергии, ScoreItem, чтобы учитвать простоту (условие score > 5 для новичков)
Из транспорта: bike и kick_scooter это наследники ScoreItem
ebike и scooter - наследники ScoreItem и EnergyConsumer(здесь решается ромбоавидная проблема, т.к. EnergyConsumer и ScoreItem виртуально наследуются)
Из предметов: helmet от InventoryItem, dock_station от EnergyConsumer
Класс Registry ни от кого не наследуется и у него нет наследников.
структура Storage ни от кого не наследуется и у нее нет наследников, нужна для оперативного доступа ко всем спискам.

unique_ptr используется при создании полей в классах, чтобы нельзя было копировать один и тот же объект внутри кода и дублировать его(да, чисто фактически, создать его можно вручную, проверки на существование такого же id среди созданных нет, но это остаётся на усмотрение пользователю)

через shared_ptr списки вещей хранят объекты. Нужны для добавления объектов в регистры в соотвествующих функциях, чтобы они не удалялись по окончанию функции.

через weak_ptr выводится объект на витрине(или не выводится, если там ничего нет), своим существованием не мешает удалять объект на витрине

Используются базовое исключения invalid_argument(), если id не число, а также созданные SimplicityError, EnergyError для проверки границ по простоте и энергии. GibberishError используется, если не удалось разобрать имя команды и отдельно InspectionError для техосмотра (broken в имени)

Используется шаблонный класс Registry - помогает полиморорфно обходить объекты в разных списках. С помощью него создаются списки всех вещей, а также потребителей энергии и "оценочных" для новичков. Эти объекты обладают разными полями и методами, поэтому Registry это типовой класс.

В креативной части:
1)новый вид транспорта kick_scooter (обычный самокат) и add для него, фактически как bike, но обладает другим describe и не ломает полиморфный обход. 
2)команда count_novice - выводит количество транспорта для новичков
3)сравнение объектов InventoryItem по id. Пригождается, когда нужно вывести в отсортированном порядке в функции list.

Буду честен, использовал ИИ для ловли ошибки, если id не число (строки if(!std::cin) {...}, cin.clear() и cin.ignore(...), работу с консолью не проходили на семинарах и лекциях, пощадите) и для помощи сборки программы (гитхабом тоже через неё учился пользоваться, пощадите)
